# 🚀 AI Code Translator

An AI-powered multi-language code translation platform that converts source code from one programming language to another using Artificial Intelligence.

AI Code Translator helps developers understand, migrate, and learn different programming languages by providing accurate code conversion, explanations, and AI-assisted coding support.

---

## 🌟 Features

### 🔄 AI Code Translation
- Convert code between multiple programming languages.
- Supports languages like:
  - Python
  - Java
  - JavaScript
  - C
  - C++

### 🤖 AI Code Explanation
- Explains code in simple language.
- Helps beginners understand complex logic.

### 🔍 Code Analysis
- Detects possible errors.
- Provides suggestions for improvement.

### 🔐 User Authentication
- User registration and login system.
- Secure password encryption using bcrypt.
- JWT-based authentication.

### 💻 Modern User Interface
- Clean dashboard design.
- Dark mode interface.
- Code syntax highlighting.
- Copy code functionality.

### 🧠 AI Assistant
- Chat-based AI coding support.
- Helps users solve programming problems.
